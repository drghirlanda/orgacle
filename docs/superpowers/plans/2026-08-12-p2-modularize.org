*Goal:* Split =orgacle.el= into focused modules, replace the hard-coded calls
between subsystems with a single extension point, put the session's state in
one explicit place, and make the remaining third-party dependencies degrade
gracefully at runtime.

*Architecture:* One leaf module (=orgacle-core.el=) holds the customization
surface, the session state and the shared helpers. Feature modules depend on
core and never on each other. =orgacle.el= depends on everything and defines
the mode, the keymap and the entry points. The coupling that exists today —
=orgacle-current-page= calling four subsystems by name, and =orgacle-show-file=
reaching into overlay state owned by the indicator code — is replaced by
=orgacle-page-hook=, which each feature module joins at load time.

*Tech stack:* Emacs Lisp, ERT, =checkdoc=, =package-lint=, GNU Make, GitHub
Actions.

* Global constraints

- Package name stays =orgacle=; symbol prefix =orgacle-=; the main file stays
  =orgacle.el= and keeps the full package header.
- Version floor stays =((emacs "29.1") (org "9.6"))=. Nothing beyond Emacs and
  Org may become a hard requirement.
- All four gates stay green after *every* task: =make compile= (with
  =byte-compile-error-on-warn=), =make checkdoc=, =make lint=, =make test=.
  CI covers Emacs 29.4, 30.2 and snapshot.
- The suite is 40 tests at the start of this phase and must never shrink.
- **No behaviour changes except where a task says so.** This phase moves code
  and changes how modules find each other. Tasks 8 and 9 change structure that
  is observable; everything before them must be a pure move.
- Every new file needs its own header line, =;;; Commentary:=, =;;; Code:=,
  a =provide= and a closing =;;; name.el ends here=, or checkdoc and
  package-lint will fail it.

- The comment above the =declare-function= block claims every call site below

    "Displaying a slide runs `orgacle-page-hook'."

    "A member that signals does not stop the others or the presentation."

              (list (lambda () (error "Deliberate failure"))

- [ ] *Step 3: Run the hook, safely*

In =orgacle-core.el=, add the runner. Every member is insulated:

#+begin_src emacs-lisp :eval no
  (defun orgacle--run-page-hook ()
    "Run `orgacle-page-hook', surviving a member that signals.
A failing member is reported in the echo area and logged, and the
remaining members still run: nothing a single subsystem does should be
able to end a presentation."
    (dolist (fn orgacle-page-hook)
      (condition-case err
          (funcall fn)
        (error
         (message "Orgacle: %s failed: %s" fn (error-message-string err))))))
#+end_src

In =orgacle-nav.el=, replace the four hard-coded calls at the end of
=orgacle-current-page= with =(orgacle--run-page-hook)=, and delete the
temporary =declare-function= forms Tasks 2 and 3 left there.

- [ ] *Step 3: Replace the ad-hoc save/restore*

Today =orgacle-mode= copies four Org variables into four =orgacle-*= globals
and =orgacle-quit= copies them back by hand, which is why adding a variable
means remembering two places. Replace with one declared list and two functions
in =orgacle-core.el=:

#+begin_src emacs-lisp :eval no
  (defconst orgacle-saved-variables
    '(org-src-fontify-natively
      org-hide-emphasis-markers
      org-pretty-entities
      org-fontify-quote-and-verse-blocks)
    "Variables Orgacle changes while presenting and restores on quit.
Adding one here is enough; both directions are handled.")

  (defvar orgacle--saved-state nil
    "Alist of (SYMBOL . VALUE) captured by `orgacle--save-user-state'.")

  (defun orgacle--save-user-state ()
    "Record the current value of every `orgacle-saved-variables'."
    (setq orgacle--saved-state
          (mapcar (lambda (sym) (cons sym (symbol-value sym)))
                  orgacle-saved-variables)))

  (defun orgacle--restore-user-state ()
    "Put every variable saved by `orgacle--save-user-state' back."
    (dolist (entry orgacle--saved-state)
      (set (car entry) (cdr entry)))
    (setq orgacle--saved-state nil))
#+end_src

Delete the four now-unused =orgacle-src-fontify-natively=,
=orgacle-hide-emphasis-markers=, =orgacle-pretty-entities= and
=orgacle-inline-image-overlays= globals — the last of which has been write-only
since the Org 9.8 shim landed. The display-table slot
(=orgacle-outline-ellipsis=) is not a variable and stays as it is.

- [ ] *Step 4: Make quit idempotent*

=orgacle-quit= currently assumes a presentation is running: it deletes a frame,
kills buffers and restores state unconditionally. Guard each step on the thing
existing, and wrap the body in =unwind-protect= so a failure part-way through
still restores what it can. Keep it to that — P3 rewrites this function around
an explicit session struct, and the goal here is only that calling it twice, or
calling it with nothing running, is harmless.
