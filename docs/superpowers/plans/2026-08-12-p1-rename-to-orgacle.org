*Goal:* Rename the package from =epresent= to =orgacle= — file, symbols, faces,
group, Org properties and keywords, user-visible strings — and ship a command
that converts existing presentation documents.

*Architecture:* The rename is mechanical but not =sed=-safe: three classes of
occurrence do not match the obvious pattern, and one pair of string literals is
coupled across two functions. The tasks therefore separate the *symbol* rename
from the *property* rename from the *string* rename, so each is verifiable on
its own, with the four gates green after every one.

*Tech stack:* Emacs Lisp, ERT, =checkdoc=, =package-lint=, GNU Make, GitHub
Actions.

* Global constraints

- Package name becomes =orgacle=; symbol prefix =orgacle-=; file =orgacle.el=.
- Org properties become =ORGACLE_*=, keywords =#+ORGACLE_*=.
- =Version:= becomes =2.0.0=. =URL:= becomes
  =https://github.com/drghirlanda/orgacle=.
- Version floor stays =((emacs "29.1") (org "9.6"))=.
- All four gates stay green: =make compile= (with =byte-compile-error-on-warn=),
  =make checkdoc=, =make lint=, =make test=. CI covers 29.4, 30.2, snapshot.
- No =EPRESENT_*= property is read at runtime. Old documents are converted by
  =orgacle-migrate-buffer=, not supported in parallel.
- Exit: no =epresent= or =EPresent= string survives outside the Commentary's
  origin note and the migration command's own patterns.

* Already done

- The GitHub repository is renamed: =drghirlanda/epresent= now redirects to
  =drghirlanda/orgacle=, and this checkout's =origin= points at the new URL.
- P0 is merged to =master= (=de929b0=) and green.

Not done, and deliberately left to the maintainer: renaming the local checkout
directory from =epresent/= to =orgacle/=. It is cosmetic, and doing it while
Emacs holds buffers in this tree would strand them.

* The three traps

A blanket =s/epresent/orgacle/g= gets all three of these wrong. Each task below
names which it owns.

** The export backend symbol is bare

=(org-export-define-derived-backend 'epresent 'latex ...)= and, in the tests,
=(org-export-as 'epresent ...)=. It is =epresent=, not =epresent-=, so a
prefix-anchored replacement misses it and the backend keeps its old name while
its functions get new ones. Same for =(provide 'epresent)= and
=(require 'epresent)=.

** The frame title is compared against a literal in another function

=epresent--get-frame= creates the frame with =(title . "EPresent")=;
=epresent-quit= decides whether to delete a frame with
=(string= "EPresent" (frame-parameter nil 'title))=. Rename one and not the
other and quitting silently stops deleting the presentation frame — no error,
the user is just left in a fullscreen frame. P3 replaces this with a session
struct; until then the two literals must move together.

** =EPresent= appears inside user-visible strings and docstrings

Fifteen occurrences: the frame title, the notes buffer name
=*EPresent Notes*=, the export menu entry ="EPresent to LaTeX"=, the
=define-derived-mode= lighter, and assorted docstrings. These are prose, not
symbols, and each needs a judgement about capitalisation — =Orgacle=, not
=orgacle=, in a sentence.

- [ ] *Step 4: Implement the migration*

Place it near the other interactive commands:

#+begin_src emacs-lisp :eval no
  ;;;###autoload
  (defun orgacle-migrate-buffer (&optional beg end)
    "Convert EPRESENT_ names to ORGACLE_ between BEG and END.
Without BEG and END, convert the whole buffer, or the region when one
is active.  Return the number of substitutions, and report it in the
echo area when called interactively.

Presentations written for epresent, the package Orgacle grew out of,
use the older names; this brings them up to date."
    (interactive (if (use-region-p)
                     (list (region-beginning) (region-end))
                   (list nil nil)))
    (let ((count 0))
      (save-excursion
        (save-restriction
          (when (and beg end) (narrow-to-region beg end))
          (goto-char (point-min))
          (while (re-search-forward "EPRESENT_" nil t)
            (replace-match "ORGACLE_" t t)
            (setq count (1+ count)))))
      (when (called-interactively-p 'interactive)
        (message "Converted %d name%s" count (if (= count 1) "" "s")))
      count))

  ;;;###autoload
  (defun orgacle-migrate-file (file)
    "Convert EPRESENT_ names to ORGACLE_ in FILE, saving it."
    (interactive "fMigrate file: ")
    (with-current-buffer (find-file-noselect file)
      (let ((count (orgacle-migrate-buffer)))
        (save-buffer)
        (message "Converted %d name%s in %s"
                 count (if (= count 1) "" "s") (file-name-nondirectory file))
        count)))
#+end_src
