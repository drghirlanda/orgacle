/Presentation mode for Emacs Org-mode/

* Installation

You can install =orgacle= from [[http://melpa.org][MELPA repository]].

** Starting a presentation

Run =M-x orgacle-run= in an Org buffer.  Earlier versions bound this to
=F5= in every Org buffer; a package may not claim a user's function keys,
so bind it yourself if you want it back:

#+begin_src emacs-lisp
  (with-eval-after-load 'org
    (define-key org-mode-map (kbd "<f5>") #'orgacle-run))
#+end_src

* Breaking changes

- =F5= no longer starts a presentation by itself. Bind it yourself if
  you want it back; see the snippet under "Starting a presentation"
  above.
- =orgacle-tooltip-mode= is now a boolean. Setting it to =0= used to
  disable tooltips; it now *enables* them, because =0= is non-nil in
  Emacs Lisp. Use =nil= to disable tooltips.
- The package is now called =orgacle=. Every command, variable and face
  is renamed from =epresent-...= to =orgacle-...=, and Org properties
  from =EPRESENT_...= to =ORGACLE_...=.
- Run =M-x orgacle-migrate-buffer= on an existing presentation to
  convert its properties, or =M-x orgacle-migrate-file= on a file.
- Settings in your init file need renaming by hand: =orgacle-migrate-buffer=
  converts presentation documents, not Emacs configuration. A
  =(setq epresent-slide-in t)= becomes =(setq orgacle-slide-in t)=.

* Basic usage

- Call =orgacle-run= on an org-buffer.
- Press =t= or =1= to view the top level of the presentation
- Navigate the presentation with =n/f=, =p/b=
- Go to a specific page with =v <num> RET=
- Scroll with =j= and =k=
- Working with code blocks:
  - =c= and =C= to navigate between code blocks
  - =e= to edit a code block
  - =x= to run it
  - =s= or =S= to toggle code block visibility
- Use =i= to split the window and load a file in the new window (see
  below).
- Use =I= to show a video fullscreen (see below).
- Press =E= to edit the slide text in place, =C-c C-c= to stop editing
- Press =+= and =-= to grow and shrink the font
- Quit with =q=

** Showing another file 

It is sometimes useful to show an additional file. This could be done
with the usual Emacs commands, but sometimes a more "polished" look is
desirable in a presentation. Orgacle supports splitting the window to
show a file in a new buffer. This functionality is activated by the
=i= key during the presentation, and it can be tested invoking =M-x
orgacle-show-file= outside of the presentation. The filename is set
through the property =ORGACLE_SHOW_FILE= and the file is showed by default
to the right of the presentation buffer. It can be shown under the
presentation by setting the property =ORGACLE_SHOW_BELOW= to a
non-nil value.

Here is an example:

#+begin_src org :eval none
    * My slide
      :PROPERTIES:
      :ORGACLE_SHOW_FILE: myfigure.pdf
      :ORGACLE_SHOW_BELOW: t
      :END:
#+end_src

Any file that can be opened in Emacs can be shown in this way. For
example, a PDF with multiple pages can be used to show more than one
figure in a sequence.
