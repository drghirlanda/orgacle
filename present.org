* Introduction

Simple presentations in Emacs
- Uses Org-mode *markup* /for text/ =and things=
- Looks pretty good
- Somewhat customizable
- Display external documents
- Live code execution

* Basics

- Write your presentation in org-mode

* Source code

Call =epresent-run= to present an Org-mode buffer.

#+begin_src emacs-lisp
  ;;;###autoload
  (defun epresent-run ()
    (interactive)
    (unless (eq major-mode 'org-mode)
      (error "EPresent can only be used from Org Mode"))
    (setq epresent--org-buffer (current-buffer))
    (epresent--get-frame)
    (epresent-mode)
    (epresent-top))
#+end_src
