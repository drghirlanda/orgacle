* Source code

Call =orgacle-run= to present an Org-mode buffer.

#+begin_src emacs-lisp
  ;;;###autoload
  (defun orgacle-run ()
    (interactive)
    (unless (eq major-mode 'org-mode)
      (error "Orgacle can only be used from Org Mode"))
    (setq orgacle--session (orgacle--session-create))
    (setf (orgacle--session-org-buffer orgacle--session) (current-buffer))
    (orgacle--get-frame)
    (orgacle-mode)
    (orgacle-top))
#+end_src

* Six -- executing source code
1. Press =c= to move to the next code block.
   #+begin_src sh
     date
   #+end_src

   #+RESULTS:
   : Sun Jun 28 12:30:51 EDT 2020

2. Press =C= to move to the previous code block.
   #+begin_src sh
     uname -a
   #+end_src

   #+RESULTS:
   : Linux darkstar 4.4.14 #2 SMP Fri Jun 24 13:38:27 CDT 2016 x86_64 Intel(R) Core(TM) i7-6500U CPU @ 2.50GHz GenuineIntel GNU/Linux

3. When a code block is executed with =C-c C-c=, the page is refreshed
   to show the results.
   #+begin_src sh
     echo "hello from a source block"
   #+end_src

   #+RESULTS:
   : hello from a source block

** Speaker notes
   Run each block live rather than reading the results off the slide; the audience already saw them appear.
